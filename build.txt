Build

To build Windows version:
.venv314\Scripts\python.exe -m PyInstaller --name="collisions-v0.3.0-alpha-windows-intel-x86_64.exe" --add-data "resources;resources" --exclude-module=PyQt5 --onefile --windowed main.py
Rename the result to suit. The exclude is needed now, probably because
SymPy makes reference to PyQt5 in sympy.plotting. GitHub's build action for
MacOS is able to see that it needs to exclude PyQt5.

MacOS:
Use build-macos.yml, which currently lives only in GitHub Actions. No exclude for
PyQt5 needed. GitHub Actions sees that it needs to exclude.
